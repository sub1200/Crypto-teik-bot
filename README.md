# Crypto Signal Bot 🤖📈

بوت يفحص أهم 30 عملة بالسيولة على Binance Futures كل 10 دقائق، ويختار **أفضل الفرص فقط**
(حتى 3 صفقات جديدة كحد أقصى بكل تشغيلة، وحد أقصى 5 صفقات مفتوحة بنفس الوقت)، ويرسلها
كتنبيه تيليغرام مع سعر الدخول والهدف ووقف الخسارة.

بعدين البوت **يراقب كل صفقة فتحها** تلقائياً: إذا وصل السعر للهدف يرسلك ✅ "تحقق الهدف"،
وإذا ضرب وقف الخسارة يرسلك ❌ "ضرب الوقف" - وتنقفل الصفقة تلقائياً من المتابعة.

الصفقات المفتوحة تُحفظ بملف `positions.json` جوا الريبو نفسه، فتضل محفوظة بين كل تشغيلة وأخرى.

## خطوات التفعيل (5 دقائق)

### 1. إنشاء بوت تيليغرام
1. افتح تيليغرام ودور على **@BotFather**
2. أرسل `/newbot` واتبع التعليمات (اختار اسم ويوزرنيم)
3. راح يعطيك **Token** شكله: `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`
4. احفظ هذا التوكن

### 2. الحصول على Chat ID
1. أرسل أي رسالة لبوتك الجديد (من تيليغرام)
2. افتح بالمتصفح:
   `https://api.telegram.org/bot<التوكن_مالك>/getUpdates`
3. دور على `"chat":{"id": ...}` وخذ الرقم - هذا الـ Chat ID مالك

### 3. رفع المشروع على GitHub
1. سوي حساب GitHub (إذا ما عندك) وسوي repository جديد (Private أفضل)
2. ارفع كل ملفات هذا المجلد إله

### 4. إضافة الأسرار (Secrets)
بالـ repository: **Settings → Secrets and variables → Actions → New repository secret**
- ضيف `TELEGRAM_BOT_TOKEN` = التوكن مالك
- ضيف `TELEGRAM_CHAT_ID` = الـ Chat ID مالك

### 5. التشغيل
- البوت راح يشتغل تلقائي كل 15 دقيقة عبر GitHub Actions (مجاني)
- تكدر تشغله يدوياً فوراً من تبويب **Actions → Crypto Signal Bot → Run workflow**

## تعديل الإعدادات
كل الحدود (thresholds) موجودة بأعلى ملف `signal_bot.py`:
- `SCAN_POOL_SIZE` - عدد العملات اللي يتم فحصها (أهم بالسيولة)
- `MAX_OPEN_POSITIONS` - أقصى عدد صفقات مفتوحة بنفس الوقت (افتراضي: 5)
- `MAX_NEW_PER_RUN` - أقصى عدد صفقات جديدة تفتح كل تشغيلة (افتراضي: 3 - الأفضل فقط)
- `STOP_PCT` / `TARGET_PCT` - نسبة وقف الخسارة والهدف من سعر الدخول (افتراضي: 2% / 4%)
- `OI_CHANGE_THRESHOLD`, `FUNDING_EXTREME`, `LS_RATIO_HIGH/LOW`, `RSI_OVERBOUGHT/OVERSOLD`
- `MIN_SCORE_TO_ALERT` - كلما رفعته، قلّت التنبيهات بس تصير أدق

## متابعة الصفقات يدوياً
ملف `positions.json` بجذر الريبو يحتوي كل الصفقات المفتوحة حالياً - تكدر تفتحه بأي وقت
من GitHub وتشوف شنو مفتوح.
